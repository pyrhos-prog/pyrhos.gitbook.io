# Escaneo de vulnerabilidades

El escaneo de vulnerabilidades es el proceso de identificar de forma automatizada debilidades de seguridad conocidas en sistemas, redes y aplicaciones. Es una fase esencial en cualquier auditoría de seguridad y forma parte del ciclo continuo de gestión de vulnerabilidades de una organización.

Esta sección cubre los fundamentos conceptuales del escaneo (cómo se clasifican y nombran las vulnerabilidades) y el uso práctico de Nessus, el escáner de vulnerabilidades más utilizado en el sector.

### Contenido de esta sección

#### Fundamentos

Antes de trabajar con un escáner es importante entender cómo se mide y clasifica la gravedad de las vulnerabilidades y cómo se identifican de forma estandarizada en toda la industria:

* **CVSS** — el sistema de puntuación numérica de 0 a 10 que utilizan todas las herramientas del sector
* **CVE y OVAL** — cómo se identifican las vulnerabilidades de forma única y cómo se detectan sin explotarlas

#### Nessus

Nessus es el escáner de vulnerabilidades de Tenable, referencia del sector para pentesting y auditorías de seguridad. Las páginas de esta sección cubren desde la instalación hasta el análisis avanzado de resultados.

### Flujo típico de trabajo

```
1. Entender la gravedad de los hallazgos → CVSS
2. Identificar las vulnerabilidades por su referencia estándar → CVE
3. Configurar y lanzar el escaneo → Nessus
4. Analizar, priorizar y exportar los resultados → Resultados Nessus
```
