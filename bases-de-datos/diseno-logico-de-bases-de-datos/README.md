# Diseño lógico de bases de datos

> El modelado de bases de datos permite representar de forma simplificada la realidad antes de construir una base de datos.

Mediante un **modelo de datos** podemos describir las estructuras, relaciones y restricciones que después servirán de base para realizar un diseño lógico correcto y coherente.

#### Modelos de datos

El modelo entidad relacion permite representar a nivel conceptual y el modelo relacional permite llevarla a nivel lógico para implementarlo en un SGBD relacional.
