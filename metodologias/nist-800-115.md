# NIST 800-115

## NIST SP 800-115

> El **NIST SP 800-115** es una guía técnica del NIST para la planificación, ejecución y reporte de pruebas técnicas de seguridad en sistemas de información.

### Fases del NIST SP 800-115

{% stepper %}
{% step %}
#### Planificación

* Definición de objetivos
* Identificación de sistemas a evaluar
* Alcance y limitaciones
* Autorizaciones legales
* Reglas de compromiso
{% endstep %}

{% step %}
#### Descubrimiento

* Identificación de activos
* Enumeración de sistemas
* Descubrimiento de puertos y servicios
* Identificación de configuraciones
{% endstep %}

{% step %}
#### Ataque

* Explotación controlada de vulnerabilidades
* Validación de fallos de seguridad
* Pruebas de acceso no autorizado
* Evaluación del impacto real
{% endstep %}

{% step %}
#### Reporte

* Documentación de resultados
* Evidencias técnicas
* Riesgos identificados
* Recomendaciones de mitigación
{% endstep %}
{% endstepper %}

### Técnicas contempladas por NIST 800-115

El estándar define tres tipos principales de pruebas técnicas:

#### Revisión

* Análisis de configuraciones
* Revisión de código
* Evaluación de políticas de seguridad

#### Pruebas de penetración

* Simulación de ataques reales
* Explotación de vulnerabilidades
* Validación de controles de seguridad

#### Evaluación de seguridad

* Escaneos automatizados
* Pruebas manuales
* Verificación de cumplimiento

### Uso habitual

El NIST SP 800-115 se utiliza principalmente en:

* Organismos gubernamentales
* Infraestructuras críticas
* Auditorías de cumplimiento
* Entornos regulados
