# ¿Porque usar una metodologia?

Un pentester no improsiva constantemente. el pentesting debe de seguir unos pasos que permitan:

1. **Reproducibilidad:** Se deben de poder seguir los pasos y conseguir los mismos resultados.
2. **Cobertura** **Completa:** Hay que auditar todas las áreas posibles.
3. **Trazabilidad:** Documentar todos los descubrimientos.
4. **Comparabilidad:** Medir la mejora o la degradación de la seguridad con el tiempo.

### Metodologías principales en el pentesting

| Metodología   | Enfoque         | Recomendado para              |
| ------------- | --------------- | ----------------------------- |
| PTES          | Flexibilidad    | Pentesting en entornos reales |
| OWASP TG      | Páginas web     | Auditorias web                |
| MITRE ATT\&CK | Amenazas reales | Threat Hunting y red team     |
| OSSTMM        | Métricas        | Auditorias globales           |
| NIST 800-115  | Normativa       | Corporaciones                 |

Se pueden mezclar partes de diferentes metodologías en un mismo pentesting para poder todas cubrir las áreas.
