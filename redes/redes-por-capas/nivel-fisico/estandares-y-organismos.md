# Estándares y organismos

> Cuando una especificación dice "802.3", "RFC 791" o "ISO/IEC 11801", hay que saber quién la publica y qué cubre. Es lo que permite que un AP de un fabricante hable con el portátil de otro.

### Tipos de estándar

| Tipo     | Origen                                | Ejemplo                                              |
| -------- | ------------------------------------- | ---------------------------------------------------- |
| De facto | Se impone por uso masivo              | Teclado QWERTY, parte de las tecnologías de Internet |
| De iure  | Aprobado formalmente por un organismo | Modelo OSI (ISO)                                     |

### Quién publica qué

| Organismo                 | Ámbito                                    | Lo que verás en la práctica                    |
| ------------------------- | ----------------------------------------- | ---------------------------------------------- |
| ITU (ITU-R, ITU-T, ITU-D) | Telecomunicaciones a escala mundial (ONU) | Radiocomunicaciones, normalización, desarrollo |
| ISO                       | Normalización internacional               | Modelo OSI, ISO/IEC 11801 (cableado)           |
| ANSI                      | Estándares en EE. UU.                     | Familia ANSI/TIA-568 (cableado)                |
| IEEE                      | Estándares técnicos                       | 802.3 Ethernet, 802.11 Wi-Fi                   |
| ETSI                      | Telecomunicaciones en Europa              | GSM, 4G, 5G                                    |
| UNE                       | Normalización en España                   | Normas UNE (AENOR certifica)                   |
| IETF                      | Protocolos de Internet                    | RFC (IP, TCP, DHCP, DNS...)                    |
| ISOC                      | Desarrollo abierto de Internet            | Apoyo a IETF y organizaciones técnicas         |
| ICANN                     | Nombres y números de Internet             | Sistema de dominios (DNS)                      |
