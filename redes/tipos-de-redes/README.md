# Tipos de redes

| **Tipo de red**                      | **Definición**                                |
| ------------------------------------ | --------------------------------------------- |
| Red de área amplia (WAN)             | Internet                                      |
| Red de Área Local (LAN)              | Redes internas (por ejemplo: Hogar u oficina) |
| Red de área local inalámbrica (WLAN) | Redes internas accesibles a través de Wi-Fi   |
| Red privada virtual (VPN)            | Conecta múltiples sitios de red a uno `LAN`   |
