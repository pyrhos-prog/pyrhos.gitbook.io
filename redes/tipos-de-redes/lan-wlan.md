# LAN/WLAN

Las redes LAN y WLAN permiten la comunicación entre dispositivos dentro de un área limitada, como una vivienda, una empresa o un campus.

**Uso habitual:**

* **LAN**: oficinas, centros de datos, entornos críticos
* **WLAN**: hogares, empresas, espacios públicos

### Red LAN (Local Area Network)

Una LAN es una red local que utiliza conexiones cableadas para interconectar dispositivos.

{% tabs %}
{% tab title="Características" %}
* Uso de cable Ethernet
* Alta velocidad y estabilidad
* Baja latencia
* Menor interferencia
* Mayor seguridad física
{% endtab %}

{% tab title="Tecnologías" %}
* Ethernet (IEEE 802.3)
* Fast Ethernet
* Gigabit Ethernet
{% endtab %}

{% tab title="Dispositivos" %}
* Switch
* Router
* PC
* Servidores
* Impresoras de red
{% endtab %}
{% endtabs %}

#### Ventajas

* Conexión estable
* Mayor rendimiento
* Menor riesgo de interferencias

#### Desventajas

* Requiere cableado
* Menor movilidad

### Red WLAN (Wireless Local Area Network)

Una WLAN es una red local que utiliza conexiones inalámbricas basadas en Wi-Fi.

{% tabs %}
{% tab title="Características" %}
* Comunicacion por radiofrecuencia
* Mayor movilidad
* Dependiente del entorno
{% endtab %}

{% tab title="Tecnologías" %}
* Wi-FI (IEEE 802.11)
* 2.4 GHz / 5 GHz / 6 GHz
{% endtab %}

{% tab title="Dispositivos" %}
* Puntos de acceso
* Router
* Dispositivos móviles
* Portátiles
* IoT
{% endtab %}
{% endtabs %}

#### Ventajas

* Movilidad
* Instalación sencilla
* Escalabilidad

#### Desventajas

* Interferencias
* Menor estabilidad
* Mayor superficie de ataque

### Diferencias entre LAN y WLAN

| Característica | LAN             | WLAN         |
| -------------- | --------------- | ------------ |
| Medio          | Cable           | Inalámbrico  |
| Estabilidad    | Alta            | Media        |
| Movilidad      | No              | Sí           |
| Latencia       | Baja            | Variable     |
| Seguridad      | Más controlable | Más expuesta |

***

### Seguridad en LAN y WLAN

#### LAN

* Control físico del acceso
* Segmentación mediante VLAN
* Firewalls y ACLs

#### WLAN

* WPA2 / WPA3
* Autenticación fuerte
* Cifrado de tráfico
* Control de APs no autorizados
