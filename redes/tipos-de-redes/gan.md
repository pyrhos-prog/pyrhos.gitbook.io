# GAN

Una GAN permite la comunicación entre sistemas y redes ubicados en **diferentes países o continentes**, utilizando tecnologías de telecomunicaciones globales como Internet, redes satelitales y enlaces submarinos.

**Ejemplos:**

* Internet
* Redes corporativas multinacionales
* Infraestructura de proveedores cloud (AWS, Azure, GCP)
* Redes gubernamentales internacionales

### Características&#x20;

* Cobertura geográfica global
* Alta dependencia de infraestructuras de terceros
* Uso de múltiples tecnologías de transmisión
* Escalabilidad elevada
* Mayor latencia comparada con LAN o MAN

### Tecnologías utilizadas

#### Infraestructura física

* Cables submarinos de fibra óptica
* Enlaces satelitales
* Redes troncales de operadores (ISP)

#### Tecnologías de red

* IP (Internet Protocol)
* MPLS
* SD-WAN
* VPN a gran escala
* BGP (Border Gateway Protocol)

#### Componentes

* Routers de borde
* Firewalls perimetrales
* Gateways VPN
* Sistemas de balanceo de carga
* Sistemas de monitorización global

### GAN vs otros tipos de red

| Tipo de red | Alcance             |
| ----------- | ------------------- |
| LAN         | Local               |
| MAN         | Metropolitana       |
| WAN         | Nacional o regional |
| GAN         | Global              |

### Uso de GAN en entornos empresariales

* Conexión entre sedes internacionales
* Acceso remoto de empleados
* Replicación de datos entre centros de datos
* Sistemas distribuidos
