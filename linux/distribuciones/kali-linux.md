# Kali Linux

### ¿Que es Kali Linux?

Kali linux es una distribución basada en [Debian](https://pyrhos.gitbook.io/pyrhos-wiki/linux/distribuciones/debian) hecha específicamente para **seguridad informática**, **auditorías**, **análisis forense digital** y **pruebas de penetración (pentesting).** La desarrolló Offensive Security.

**Kali Linux trae herramientas preinstaladas para diferentes tareas:**

* Análisis de vulnerabilidades
* Pruebas de penetración
* Ingenieria inversa
* Recopilación de información
* Explotación de sistemas
* Análisis forense
* Pruebas de seguridad inalámbrica
